# I Ching gold artwork

The calculator's existing iching.png and iching-dark.png are both replaced by the same warm gold octagonal medallion at their original 200 × 200 PNG dimensions, with alpha outside the octagon. The eight trigram shapes and central disc come from the original image alpha, scaled uniformly onto a generated blank gold octagonal substrate. Trigram line order and solid/broken topology are preserved rather than generated. Both existing light/dark image paths and UI visibility rules remain in place.

The HTML hexagram uses the existing shared magic-square gold plate at 167px width, with a 167px square backing (4px larger overall, adding 2px clearance per side) and centred flex layout. Container padding is 18px. Each of its six bars remains 124 × 10px with 9px spacing. Yin gaps remain exactly 20px wide (52px to 72px), now truly transparent via a split CSS gradient instead of a white overlay. Ordinary bars use deep bronze; changing bars retain the existing vibrant-orange theme token. A restrained lower edge adds relief. Hexagram model, line order, changing-line state, form submission, labels and interpretations are unchanged.

LESS and compiled CSS use their respective correct relative Images paths for virtual-directory installations. The shared plate is already registered for publishing; no duplicate backing asset is added. Catalogue revisions are regenerated. Validation covers original icon dimensions, PNG encoding and alpha, identical theme variants, source/compiled bar geometry, transparent yin gaps, changing-colour token and catalogue checks. Browser rendering and the Windows build are not executed here.
